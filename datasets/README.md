# SentinelX sample datasets (synthetic)

Fictional Nova Bank telemetry generated by `backend/app/demo/generator.py`. Timestamps are relative to the export date. Upload any file on the *Upload Security Data* page.

| Dataset | Rows | Contents |
|---|---|---|
| `normal` | 455 | Three days of ordinary Nova Bank activity. Expected: no detections. |
| `brute_force` | 545 | Password spraying plus a brute-force that succeeds (followed by the full intrusion chain). |
| `privilege_escalation` | 466 | A user adds themself to Domain Admins; an admin account dumps credentials. |
| `powershell` | 460 | Macro-enabled document launching a hidden PowerShell download cradle. |
| `exfiltration` | 467 | Bulk payroll file access followed by uploads to consumer cloud storage. |
| `mixed` | 2315 | All scenarios, exported with alternate field names (src_ip, username, hostname...) to exercise normalization. |
